# 立ち絵の置き場所

ここに画像を置くと、SVGで描いたキャラの代わりにその画像が使われます。
**アプリの再起動もビルドも不要です。置いてリロードするだけ。**

いまは4人ぶんの立ち絵が入っています。

| キャラ | 衣装 |
|---|---|
| アイミー（1枚絵） | ビキニ＆パレオ / セーラー服 / 制服（アクセなし） / パーカー（表情ちがい2枚つき） / ビーチカバーアップ / マーメイドドレス（表情ちがい1枚つき） / スーツ / ルームウェア |
| アイミー（重ねて作る） | ブレザー / ダボシャツ / パジャマ / ナイトウェア / ワンピース / ロリータドレス / ばんそうこうビキニ / ハート水着 / ランジェリー |
| なぎ | ストリート |
| ひなた | ブレザー |
| れな | スーツ |

しずくと、上記以外の衣装はSVGで描かれます。混在して問題ありません。

置き方は2通りあります。どちらを使っても構いません。

| やり方 | 特徴 |
|---|---|
| **1枚絵**（`<衣装ID>.png`） | 手軽。1枚置けばすぐ出る |
| **重ねて作る**（`parts/`） | 体と頭を分けて置く。頭を1枚足すと**全衣装に一度に効く** |

## 置き方

```
public/characters/<キャラID>/<衣装ID>.png
```

例:

```
public/characters/aimi/swimsuit.png    ← アイミーのビキニ姿
public/characters/aimi/sailor.png      ← アイミーのセーラー服姿
public/characters/aimi/default.png     ← 衣装別の画像が無いときに使われる
```

`default.png` だけ置けば、どの衣装を選んでもその1枚が出ます。
まず1枚から試すのがおすすめです。

拡張子は `.png` `.jpg` `.webp` `.avif` `.gif` が使えます。

## 表情ちがいを置く

ファイル名のうしろに `@表情` を付けると、会話の内容に応じて自動で切り替わります。

```
public/characters/aimi/swimsuit.png         ← ふだんの顔
public/characters/aimi/swimsuit@happy.png   ← 笑っているとき
public/characters/aimi/swimsuit@shy.png     ← 照れているとき
```

使える表情は7つです。

| 表情ID | どんなとき |
|---|---|
| `normal` | ふだん（`@` なしのファイルが使われます） |
| `happy` | うれしい・笑っている |
| `shy` | 照れている |
| `sad` | しょんぼり・心配している |
| `angry` | むくれている |
| `surprised` | 驚いている |
| `sleepy` | 眠そう |

置いていない表情は、自動で `@` なしの画像に戻ります。
まず `@happy` と `@shy` の2つを足すだけでも、かなり表情豊かになります。

> **顔だけ差し替えるコツ**：画像生成のシードとプロンプトを固定したまま、
> 表情の指定だけ変えて出し直すと、体や服がほぼ同じ絵になります。
> 体がずれると切り替わった瞬間に飛んで見えるので、そこだけ揃えてください。

## 重ねて作る立ち絵（パーツ分け）

1枚絵は「服も髪も顔も焼き付いた1枚」なので、髪型を1つ増やすだけでも
衣装の枚数ぶん描き直しになります。体と頭を分けて置くと、
**頭を1枚足すだけで、その体すべてに効きます**。

```
public/characters/<キャラID>/parts/body/<衣装ID>.png   ← 首から下（服＋ポーズ）
public/characters/<キャラID>/parts/head/<髪型ID>.png   ← 首から上（髪＋顔）
public/characters/<キャラID>/parts/anchors.json        ← どこに置くかの寸法
```

`anchors.json` は、どのパーツをどの位置に重ねるかを書いた寸法表です。

```jsonc
{
  // 全パーツ共通の下地。すべての座標はこの中の位置で書く
  "canvas": { "w": 749, "h": 1773 },
  "body": {
    "blazer": {
      "w": 457, "h": 1405,   // 画像そのものの大きさ
      "x": 136, "y": 353,    // 下地の中で画像の左上を置く位置
      "neckX": 370, "neckY": 349,  // 首の位置。頭はここに合わせて載る
      "pose": "touchcheek"   // この絵がとっているポーズ（下記）
    }
  },
  "head": {
    "short": {
      "w": 316, "h": 355, "x": 194, "y": 26,
      "neckX": 344, "neckY": 368,
      // 照れ線や♪を顔に合わせて置くための目印
      "face": { "eyeY": 253, "headX": 352, "cheekDX": 62,
                "cheekY": 305, "markDX": 178, "markY": 69 }
    }
  }
}
```

コツは **すべてのパーツを同じ縮尺・同じ下地で切り出すこと**。
そうすれば拡大縮小せず、首の位置を合わせて重ねるだけで絵になります。
元にした立ち絵が同じアプリの同じ画面なら、たいてい縮尺は揃っています。

`anchors.json` に載っていない画像は「置く場所が分からない」ので無視されます。
`head` が1つも無いときは、1枚絵のほうにフォールバックします。

### ポーズ札（`pose`）

写真は描かれたポーズしか取れません。そこで体パーツに、その絵が
どのポーズなのかを書いておきます。

- クローゼットで「立ち絵のまま」を選んでいるあいだは、いつも写真が出ます
- 札と同じポーズを選んだときも写真が出ます
- 違うポーズを選ぶと、どんな組み合わせでも描けるSVGに切り替わります

使えるポーズIDは `asis`（立ち絵のまま） / `natural` / `armsout` /
`armsdown` / `apart` / `touchcheek` / `handhip` / `wave` / `behind` です。

## 画像の作り方のコツ

- **背景は透過**（透過PNG）にしてください。アプリ側の背景に重ねて表示します
- **縦長**（例 800×1400 くらい）で、**足元が画像の下端**に来るように切り抜くと座りが良いです
- 同じキャラの衣装違いを作るときは、**画像生成のシードとプロンプトを固定**して服だけ変えると顔が揃います
- 背景を消すツール: [rembg](https://github.com/danielgatis/rembg)、Photoshop の「被写体を選択」、[remove.bg](https://www.remove.bg/) など

## 注意

1枚絵を使っているあいだ、**髪型・目・口などのパーツ変更はその衣装には反映されません**
（絵に焼き付いているため）。クローゼットでもその旨が表示されます。
画像を置いていない衣装は、これまでどおりSVGで描かれてパーツ変更が効きます。

パーツ分けにしてある衣装は、**頭だけは差し替わります**（`parts/head/` に置いたぶん）。
服そのものの形と、その絵のポーズは写真に焼き付いたままです。
ポーズを変えたいときは、クローゼットの「ポーズ」から選ぶとSVGに切り替わって、
どの衣装・どの髪型とでも自由に組み合わせられます。

クローゼットの衣装一覧では、画像が用意されている衣装に 📷 が付きます。
