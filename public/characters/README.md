# 立ち絵の置き場所

ここに画像を置くと、SVGで描いたキャラの代わりにその画像が使われます。
**アプリの再起動もビルドも不要です。置いてリロードするだけ。**

いまは4人ぶんの立ち絵が入っています。

| キャラ | 衣装 |
|---|---|
| アイミー | ビキニ＆パレオ |
| なぎ | ストリート |
| ひなた | ブレザー |
| れな | スーツ |

しずくと、上記以外の衣装はSVGで描かれます。混在して問題ありません。

## 置き方

```
public/characters/<キャラID>/<衣装ID>.png
```

例:

```
public/characters/aimi/swimsuit.png    ← アイミーのビキニ姿
public/characters/aimi/sailor.png      ← アイミーのセーラー服姿
public/characters/aimi/default.png     ← 衣装別の画像が無いときに使われる
```

`default.png` だけ置けば、どの衣装を選んでもその1枚が出ます。
まず1枚から試すのがおすすめです。

拡張子は `.png` `.jpg` `.webp` `.avif` `.gif` が使えます。

## 画像の作り方のコツ

- **背景は透過**（透過PNG）にしてください。アプリ側の背景に重ねて表示します
- **縦長**（例 800×1400 くらい）で、**足元が画像の下端**に来るように切り抜くと座りが良いです
- 同じキャラの衣装違いを作るときは、**画像生成のシードとプロンプトを固定**して服だけ変えると顔が揃います
- 背景を消すツール: [rembg](https://github.com/danielgatis/rembg)、Photoshop の「被写体を選択」、[remove.bg](https://www.remove.bg/) など

## 注意

立ち絵の画像を使っているあいだ、**髪型・目・口などのパーツ変更はその衣装には反映されません**
（絵に焼き付いているため）。クローゼットでもその旨が表示されます。
画像を置いていない衣装は、これまでどおりSVGで描かれてパーツ変更が効きます。

クローゼットの衣装一覧では、画像が用意されている衣装に 📷 が付きます。
